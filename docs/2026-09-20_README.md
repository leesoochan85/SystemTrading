3. HighBreakout 매수 조건 변경

변경 전

현재가 > 직전 60거래일 최고가
당일 누적거래량 >= 최근 20거래일 평균거래량
최근 20거래일 평균거래대금 >= 20억원

변경 후

다음 조건을 모두 만족해야 매수 신호가 발생합니다.

현재가 >= 오늘을 제외한 직전 60거래일 최고가 × 0.95
현재가 > 전일 완결 일봉 고가
당일 누적거래량 >= 최근 20거래일 평균거래량
최근 20거래일 평균거래대금 >= 20억원
유효한 Wilder ATR(14) 계산 가능
현재가 - 2 × ATR(14) > 0

변경 결과:

60일 최고가보다 5% 넘게 낮으면 매수하지 않습니다.

최고가 대비 -5%~0% 구간도 매수 대상에 포함됩니다.

60일 최고가와 같거나 돌파한 이후에도 상한 없이 매수할 수 있습니다.

현재가가 전일 완결 일봉 고가보다 반드시 높아야 합니다.

오늘 진행 중인 미완성 일봉은 기준값 계산에서 제외합니다.

매수 신호 사유 코드:

HIGH_ZONE_OR_BREAKOUT_ENTRY

가격 예시

직전 60일 최고가: 10,000원
전일 고가: 9,700원

현재가  9,400원 → 매수 불가: 60일 최고가의 95% 미만
현재가  9,500원 → 매수 불가: 전일 고가 미돌파
현재가  9,800원 → 나머지 조건 충족 시 매수 가능
현재가 10,000원 → 나머지 조건 충족 시 매수 가능
현재가 10,500원 → 전고점 돌파 후에도 매수 가능

실제 주문은 기술적 신호 외에도 기존 안전조건을 통과해야 합니다.

동일 종목 미체결 주문 없음

4. HighBreakout ATR 매도

기존 매도 조건을 다음과 같이 변경했습니다.

제거한 조건

수익률 -5% 이하 고정 손절
현재가의 동적 MA20 이탈 매도

새로운 ATR 조건

ATR 기간 = Wilder ATR(14)

초기 청산선
= 실제 평균 매입가 - 2 × 진입 직전 ATR(14)

추적 청산 후보
= 진입 이후 최고 완결 종가 - 3 × 해당 완결 일봉 ATR(14)

최종 청산선
= max(기존 청산선, 초기 청산선, 추적 청산 후보)

현재가가 최종 청산선 이하가 되면 매매가능수량 전부를 시장가로 매도합니다.

매도 신호 사유 코드:

ATR_INITIAL_STOP
ATR_TRAILING_STOP

계산 예시

실제 평균 매입가: 10,000원
진입 직전 ATR(14): 300원

초기 청산선 = 10,000 - 2 × 300
             = 9,400원

이후 진입 후 최고 종가가 11,500원이고 해당 일봉 ATR이 350원이면:

추적 청산 후보 = 11,500 - 3 × 350
                 = 10,450원

최종 청산선 = max(9,400, 10,450)
             = 10,450원

운영 규칙:

True Range에 전일 종가 대비 상승·하락 갭을 포함합니다.

최초 ATR은 14개 True Range의 단순평균으로 시작합니다.

이후 ATR은 Wilder 방식으로 평활합니다.

추적 청산선은 완결된 일봉으로만 갱신합니다.

장중 고가가 아니라 진입 이후 최고 완결 종가를 사용합니다.

ATR이 커져도 기존 청산선보다 낮아지지 않습니다.

별도의 고정 익절 목표가는 두지 않습니다.

7. Windows SQLite 연결 오류 수정

최초 테스트에서는 다음 오류가 발생했습니다.

PermissionError: [WinError 32]
다른 프로세스가 파일을 사용 중이기 때문에 프로세스가 액세스 할 수 없습니다.

원인:

Python의 SQLite 연결 컨텍스트는 트랜잭션을 종료하지만 연결 객체 자체를 자동으로 닫는 용도가 아니어서, Windows가 테스트용 임시 DB 파일을 삭제하지 못했습니다.

수정:

market_history.py의 연결을 컨텍스트 매니저로 변경했습니다.

정상 처리 시 커밋, 예외 발생 시 롤백하도록 유지했습니다.

finally에서 con.close()를 호출하도록 했습니다.

테스트에서 contextlib.closing()으로 임시 DB 연결을 명시적으로 닫았습니다.
